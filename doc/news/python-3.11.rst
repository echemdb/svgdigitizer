**Changed:**

* Changed the minimum versions of dependencies to the first releases that support Python 3.11: astropy 5.0.5, matplotlib 3.6, pandas 1.5, pillow 9.2, and scipy 1.9.2.

**Removed:**

* Removed support for Python 3.10, which reached its end of life in October 2026. svgdigitizer now requires Python 3.11 or later.
